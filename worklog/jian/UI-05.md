## Changes
- One vendor list replaces the bar chart, the "All vendor values" table and the separate queue: flagged vendors first, To check / Checked / All vendors tabs, details in a side panel. Acting on a vendor keeps it selected, so reviewing never swaps the panel. On phones, selecting a vendor scrolls smoothly to its details.
- Flag cards lead with "Why flagged" (plain sentence plus the rule), then the answer in one line, short bullets, a check line ("Checked against the records" or "Not verified: <reason>"), next step, evidence chips that open the record inline, Mark reviewed, and a one-line Details summary. Badges only where they carry information (Placeholder in stub mode, Investigating, Didn't finish).
- Live progress while a run is active: animated bar, plain steps from the recorded lookups ("Read invoice NS-2026"), the current step, lookups used and elapsed time. Steps come from tool names and requested IDs only, never model text (INV-07).
- Copy cut across header, company picker, Help (3-step tour, 5 short answers), About and "How to read this". "Synthetic demo data" appears once.
- Fictional names: HubSpot → Larkspur Software, GXO Logistics → Ironbridge Logistics; page links use `larkspur` / `ironbridge`, old `?company=hubspot|gxo` links still work. Internal IDs and stored prefixes unchanged (takes over the names criterion of #59).
- Contract: optional `Finding.summary` and `Finding.supportNote`; `Run.activity` (default `[]`, so stored runs still parse). Store gets `recordActivity` (display only; failures never affect a run). Prompt v2 asks for dollars, a one-line summary and bullets.
- Custom select chevron with padding; animations respect reduced motion.
