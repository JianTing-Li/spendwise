## Approved HTTP test repair

Elliot explicitly approved a test-only fix. The test now uses `redirect: 'manual'`, asserts `307` and the exact canonical `Location`, and checks the access-required page with invalid hosted configuration (where canonical redirection is intentionally unavailable). Existing API assertions for missing identity, denied permission, authorized actions and cross-origin rejection remain. Application security behavior is unchanged.
