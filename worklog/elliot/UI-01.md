## Changes and decisions

- `src/app/use-demo.ts`: observe durable pending/running runs while the existing
  mutation request owns execution. Sequential reads, abort cleanup, request
  ordering, mutation epochs and a monotonic generation guard prevent stale
  reads and superseded mutation responses from restoring old findings/review.
  A synchronous mutation ref prevents repeat clicks before disabled rendering.
  Reset can supersede execution and clears visible scenario state immediately.
- Progress shows actual run states and recorded counters, never a fabricated
  percentage. Read failures pause polling and say progress is unavailable;
  explicit Reload can recover while execution continues. No automatic mutation
  retry. Read 401/403 and mutation 401 clear visible records; mutation-only 403
  preserves readable records. 409 requests a current-state reload.
- `src/app/review-card.tsx`: stored exception settings and application-calculated
  prior/current/change cash amounts, periods and triggered records. Finding
  citations open source records and move keyboard focus to the exact payment,
  invoice or note. Missing/cross-vendor citations are visibly unavailable.
  Source text stays escaped React text, including hostile note markup.
- Separate completed execution, verified record explanation, draft/unresolved
  findings, and human acknowledgment. A verified badge requires real mode,
  completed execution and the existing Explained/valid/supported combination.
  Review displays its run identity, generation and UTC timestamp; acknowledgment
  does not change support, approve payments or verify next-step wording.
- Retain predecessor-based explicit retry, three-attempt cap, expandable history,
  and per-attempt 8 retrieval/10 model request/60-second limits. The existing
  authorized review/retry/store contracts already provide persistence,
  idempotency and generation enforcement; no contract or server change was needed.
- `src/app/dashboard.tsx`, `format.ts`, `globals.css`: integrate the hook/card,
  shared USD display formatting, mobile layout, evidence focus and state styling.
  Existing global synthetic/stub labels remain visible. No domain calculation,
  agent/evaluator, fixture, migration, dependency, configuration or CI edits.
